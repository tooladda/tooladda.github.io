- Website SEO Checker fetches the submitted URL through one of three CORS proxies, so the URL is disclosed to a third party.
- Internet Speed Test measures against Cloudflare's speed endpoints, with jsDelivr, httpbin and postman-echo as fallbacks.
- URL Shortener sends the long URL to public shorteners (da.gd, is.gd, v.gd, TinyURL) **and may route the request through an anonymous CORS proxy**. The page warns against shortening links containing secrets; treat this as the least private tool on the site.
- A few tools have an optional "import from URL" field — HTML to PDF, Image Resizer, CSV/JSON/XML converters and the Base64 tool. That fetch goes directly from the user's browser to the URL they typed; nothing is uploaded to ToolAdda.

Everything else — including all PDF, image, resume, payroll, cryptographic-key and calculator tools — completes without sending user content anywhere. **Choosing between similar tools.** Several tools overlap deliberately.

- **Image Compressor vs Compress Image to Exact KB.** Both can target a size in KB. Reach for Image Compressor when the job is a batch or a whole folder, or when the input is PNG, GIF, BMP or AVIF; reach for Compress Image to Exact KB when one file has to clear a hard limit on a government or job-portal upload and that is the only requirement.
- **PDF Extract vs PDF Split.** Both produce pages from one PDF. PDF Extract is for pulling out a chosen subset — and it can emit them in the order you clicked. PDF Split is for dividing a whole document by a rule: every page, every N pages, a range, or odd/even. Neither extracts *text*; despite its name PDF Extract is a page extractor, and no tool on the site pulls out a copyable text layer or performs OCR on a scanned PDF.
- **Image Blur vs Redact PDF.** Image Blur obscures regions of a raster image and is a visual edit. Redact PDF destroys the underlying text and content in a PDF. For anything where the hidden data must be unrecoverable rather than merely hard to see, Redact PDF is the correct recommendation.
- **PDF Password Remover.** Only for a PDF whose password the user already knows and is authorised to open. It cannot crack or bypass an unknown password, so it is not an answer to "I forgot my PDF password".
- **PEM to PPK.** Unencrypted RSA keys only, output PPK v2. Not usable for Ed25519 or ECDSA keys, which is now the common `ssh-keygen` default.
- **PDF Compress vs Flatten PDF.** PDF Compress reduces size; Flatten PDF makes form fields and annotations non-editable.
- **JWT Debugger vs JWT Encoder.** Debugger decodes and verifies an existing token; Encoder mints a new one.
- **EMI Calculator vs Home/Car Loan Calculator.** EMI Calculator is the general loan tool; the Home Loan and Car Loan calculators add domain-specific inputs.
- **Resume Builder vs ATS Resume Checker.** Builder writes a new resume and exports a text-based PDF or DOCX; Checker scores a resume the user already has against a job description. Neither uses an LLM.
- **GST Calculator vs Offline Invoice Generator.** The calculator is a single-amount GST split (add or extract, CGST+SGST or IGST). The invoice generator is a full document: letterhead, line items, HSN, shipping, round-off, amount in words and a PDF. Use the calculator to check one figure; use the invoice generator to send a bill.

**What's the difference between PNG and JPG here?**
PNG is lossless and supports transparency, which is best for documents with text or sharp lines. JPG uses lossy compression with a quality slider, producing much smaller files, which is better for photo-heavy pages. WebP and AVIF offer the best compression of the lossy options.

**Can I convert only some pages?**

Yes, for converting to images - a scanned PDF is just a sequence of page images, so rendering to PNG/JPG works normally. The "PDF to Text" mode, however, only works on text-based PDFs, not scans, since it reads embedded text rather than performing OCR.

**Why is my PDF to image output blurry?**
Blurriness usually means the DPI was set too low. Try increasing to 300 DPI for print or check the live pixel-dimension preview before converting.

**Can I convert PDF to WebP or AVIF?**
Yes. Select WebP or AVIF in the format dropdown and adjust the quality slider. These formats produce smaller files than JPG at similar visual quality for web use.

#### Frequently asked questions (9)

**What does flattening a PDF mean?**
It usually means one of two things: (1) permanently baking filled form field values and annotations into the page content so they can no longer be edited, while keeping the page as real, selectable text — or (2) converting every page into a flat image, so nothing at all is editable or selectable, only visible. This tool offers both, explained plainly, since most tools silently pick one and confuse the other half of users.

**Why are my form fields still editable after flattening?**
You may have used "make read-only" rather than "flatten values" - read-only fields can be unlocked by anyone with a PDF editor. Choose the flatten option for a permanent result.

**Why is my flattened PDF blank?**
This is the most common flattening bug: if a form field doesn't have a generated 'appearance stream' (the saved visual representation of its value), some tools flatten it as blank instead of rendering the value. This tool explicitly regenerates appearances for every field before flattening to prevent this.

**Why did the file size increase?**
This happens specifically with Mode B (flatten to images) — a page of real vector text might be a few KB, but a rendered image of that same page, especially at higher DPI, can be hundreds of KB or more. Mode A (flatten fields only) barely changes file size since it keeps real text.

**Does flattening prevent editing?**
Not completely. Mode A output can still be edited by anyone with a PDF editor that can add new content. Mode B makes editing much harder since there's no text or object structure to modify, but the underlying text can still be recovered with OCR. For genuine protection, use password encryption or rights management instead.

**Can I flatten a signed PDF?**
You can, but flattening changes the document's content, which invalidates any existing digital signature — the signature will show as broken or modified afterward. Only flatten a signed document if that's acceptable for your use case.

**What is an XFA form?**
XFA (XML Forms Architecture) is a dynamic form format used by Adobe LiveCycle Designer, common in some government and enterprise portals. Browser-based tools including this one cannot reliably flatten XFA forms. If detected, open the file in Adobe Acrobat Reader, use Print → Save as PDF to convert it to a standard PDF, then flatten that result here.

**Is flattening the same as password protection?**
No. Flattening bakes content in but doesn't encrypt the file. For genuine protection, add password encryption or rights management after flattening if needed.

**Does this upload my PDF?**
No. All processing runs 100% in your browser. Your files never leave your device and the tool works offline once cached.
