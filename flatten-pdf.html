Free Online PDF Flattener — Lock Form Fields or Rasterize Pages

Flattening a PDF permanently bakes content into the page so it can't be changed later. But which content, and how it's baked in, matters enormously. ToolAdda explains both approaches in plain language: Mode A locks filled form fields and annotations while keeping real, selectable text; Mode B converts every page into a flat image where nothing is editable or searchable. Choose the one that matches your actual need — not what a random tool silently picked for you.

Frequently asked questions

What does flattening a PDF mean?

It usually means one of two things: permanently baking filled form values and annotations into selectable page text, or converting every page into a flat image where nothing is selectable. This tool offers both, explained plainly.

Why are my form fields still editable after flattening?

You may have used "make read-only" rather than "flatten values" — read-only fields can be unlocked by anyone with a PDF editor. Choose the flatten option for a permanent result.

Why is my flattened PDF blank?

The most common bug: a field without a generated appearance stream can flatten as blank. This tool explicitly regenerates appearances for every field before flattening.

Why did the file size increase?

Only with Mode B — a vector text page might be a few KB, but a rendered image of it, especially at higher DPI, can be hundreds of KB. Mode A barely changes size.

Does flattening prevent editing?

Not completely. Mode A can still be edited with a PDF editor. Mode B is much harder to edit but text can still be recovered with OCR. Use password encryption for real protection.

Can I flatten a signed PDF?

Yes, but it invalidates the existing digital signature since the content changes. Only do this if that's acceptable.

What is an XFA form?

A dynamic form format (Adobe LiveCycle) used by some government portals. Browser tools can't flatten it reliably — open it in Adobe Acrobat Reader, Print → Save as PDF, then flatten that result here.

Does this upload my PDF?

No. All processing runs 100% in your browser. Your files never leave your device and the tool works offline once cached.

Is flattening the same as password protection?

No. Flattening bakes content in but doesn't encrypt the file. For genuine protection, add password encryption or rights management after flattening if needed.
