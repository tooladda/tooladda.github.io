    What is a QR code?

    A QR (Quick Response) code is a two-dimensional barcode made up of a grid of black and white squares that encodes data — most commonly a website link, but also plain text, Wi-Fi credentials, contact details, payment information and more. Unlike a traditional 1D barcode, which only stores data along a single line, a QR code stores information both horizontally and vertically, letting it hold hundreds of times more data in the same amount of space. QR codes were originally invented in 1994 by the Japanese company Denso Wave to track automotive parts on a factory floor, and their combination of speed, storage capacity and built-in error correction has since made them the default way to bridge a printed or displayed surface with a digital action.

    Today you’ll find QR codes on restaurant tables for digital menus, on product packaging for authenticity checks, on posters and billboards for marketing campaigns, on invoices for UPI or other digital payments, on business cards for instant contact saving, and on Wi-Fi routers for one-scan network joining. Their popularity comes down to one thing: a QR code turns something a camera can see into something a device can act on, instantly and without typing.

    How QR codes work

    A QR code encodes data using a pattern of black modules (squares) arranged on a white background, laid out inside a square grid. Three large squares in the corners — called finder patterns — let a scanner instantly recognize the code and work out its orientation, even if the code is rotated, tilted, or viewed at an angle. Smaller alignment patterns keep the grid readable even when the surface is slightly curved or the photo is a little distorted, and timing patterns (alternating black-and-white strips) let the decoder know exactly how large each module is.

    The actual data is encoded using a system called Reed-Solomon error correction, which is why QR codes can still be read even if part of the code is scratched, dirty, or covered by a small logo. Depending on the error-correction level chosen when the code was generated, a QR code can lose anywhere from 7% to 30% of its pattern and still decode correctly. This is also why professionally designed QR codes can safely have a logo placed in the center — the encoding intentionally leaves enough redundancy to compensate for it.

    When a scanner (like a phone camera or this tool) looks at the code, it locates the finder patterns, corrects for perspective and rotation, reads each module as a 1 or a 0, then reverses the Reed-Solomon encoding to recover the original bytes. Those bytes are then interpreted according to a data-type prefix — for example WIFI:, MAILTO:, tel:, BEGIN:VCARD or a plain URL — which is exactly how this scanner is able to automatically tell a Wi-Fi code apart from a website link.

    How to scan a QR code online

    Scanning a QR code online means decoding it inside your web browser instead of using a dedicated phone app. With this tool, you have two ways to do it: point your device’s camera at a code in the “Camera” tab for a live, real-time scan, or switch to “Upload & paste” to decode a code from an existing image — a screenshot, a downloaded photo, or one pasted straight from your clipboard. Both paths use the same underlying decoding engine, so the result is identical either way; the only difference is where the image comes from.

    Camera scanning is best when the QR code is physically in front of you right now — on a poster, a menu, a product, or someone’s screen. Image upload is best when you already have a picture that contains a code — a screenshot of a payment QR someone sent you in chat, a photo you took earlier, or an image saved from an email. Because this scanner supports both, you’re never stuck without a way to read a code.

    Camera scanning vs. image scanning

    Camera scanning gives you a continuous, real-time feed: point, hold steady, and the decoded result appears the instant the code is recognized, with a laser-style scan animation and corner guides helping you line it up. It needs camera permission and a secure (https) connection, and it works best with good lighting and a steady hand. Image scanning, on the other hand, works from a single still frame, so it’s more forgiving of shaky hands and works on any desktop or laptop even without a webcam — you just need the image file itself. It also supports batch scanning: select several images at once and each one gets decoded in its own turn.

    A practical rule of thumb: use the camera for codes you can physically point at, and use upload for codes that already exist as an image somewhere — a screenshot, a downloaded picture, or a photo from your gallery.

    Types of QR codes this scanner decodes

    QR codes aren’t limited to website links. The data prefix inside the code tells a scanner exactly what kind of content it holds, and this tool automatically recognizes and formats each of the following:

    URL QR codes

    The most common type — the code stores a plain http:// or https:// web address. This scanner shows the destination domain, runs a quick safety check, and gives you a one-tap “Open” button so you never have to retype a link.

    Wi-Fi QR codes

    Encoded as WIFI:T:WPA;S:NetworkName;P:password;;, these let a device join a wireless network without anyone typing the password. The scanner parses out the network name (SSID), password and encryption type, with a show/hide toggle for the password and a one-tap copy.

    Contact (vCard) QR codes

    A vCard code stores a full digital business card — name, phone, email, organization — in the BEGIN:VCARD…END:VCARD format. The scanner extracts the fields and lets you download it as a .vcf file that any phone can import straight into contacts.

    Payment (UPI & crypto) QR codes

    UPI codes (used widely across India) encode a payee name, UPI ID and sometimes a fixed amount in a upi://pay?... link. The scanner breaks these fields out individually and offers to open the linked payment app. Bitcoin address codes (bitcoin:) are recognized as well.

    Business & social QR codes

    Links to WhatsApp (wa.me), Telegram (t.me), Zoom or Google Meet invitations, App Store / Play Store listings, and common social platforms are all identified with a friendly label so you immediately know what you’re about to open.

    Beyond these, the scanner also recognizes plain text, email (mailto:), phone numbers (tel:), SMS (smsto:), geographic coordinates (geo:) and calendar events (BEGIN:VEVENT).

    Dynamic vs. static QR codes

    A static QR code encodes its final content directly — what you scan is exactly what was created, and it can never be changed. A dynamic QR code instead encodes a short redirect link controlled by the generator service; scanning it sends the device through that redirect to whatever destination the creator currently has configured, which means the underlying destination can be updated at any time without reprinting the code. Dynamic codes also typically offer scan analytics (how many times, from where, on what device), which is useful for marketing campaigns, while static codes are simpler, more transparent, and better suited to permanent information like Wi-Fi credentials or a personal contact card.     QR code security: what to know

    A QR code is only as trustworthy as the content it points to — the pattern itself can’t carry malware, but the link it opens absolutely can lead somewhere unsafe. This is why this scanner shows a link safety indicator instead of just opening URLs blindly. It checks whether the destination uses HTTPS, extracts and displays the domain so you can verify it before tapping through, flags known URL-shortener services (since a shortened link hides its real destination until you click), warns on unusual schemes, IP-address hosts, or punycode / lookalike domains, and only ever treats standard http/https links as directly openable — anything else is shown as text so it can’t silently trigger an unexpected action.

    These checks are a helpful first line of defense based on well-known heuristics, not a full antivirus or threat-intelligence scan — always apply your own judgment, especially for codes from an untrusted or public source.

    How to avoid fake or malicious QR codes

    • Check for tampering — a sticker placed over a legitimate QR code (common on parking meters and payment stands) is a classic scam. Look for peeling edges or a sticker that doesn’t quite match the surrounding print.
    • Read before you tap — this scanner shows you the decoded destination before opening it, rather than jumping straight there like most phone camera apps do.
    • Verify the domain — check that the domain shown matches who you expect (your bank, the restaurant, the event organizer) rather than a similar-looking substitute.
    • Be wary of urgency — codes that promise a prize, demand “immediate” payment, or push you to “verify your account” are common phishing patterns.
    • Avoid entering sensitive info on an unexpected page — if a scanned link asks for a password or card details somewhere you didn’t expect, stop and verify independently.

    Scanning QR codes on mobile

    On a phone, this scanner works entirely inside your mobile browser — no camera app switch needed. Tap “Start camera”, allow permission when prompted, and hold the code inside the frame; the large touch targets, sticky scan button and responsive camera view are all designed mobile-first. If you already have the code saved as a photo, switch to “Upload & paste” and pick it from your gallery instead. iOS and Android both work well in their default browsers (Safari and Chrome respectively), and any modern Chromium-based mobile browser benefits from faster native detection.

    Scanning QR codes on desktop

    Desktop scanning is where a browser-based tool really shines over an app: if your laptop has a webcam, camera scanning works exactly the same as on mobile. If it doesn’t, image upload still gets the job done — drag a screenshot or saved photo straight onto the page, paste an image copied from anywhere with Ctrl+V (Cmd+V on Mac), or click to browse for a file. This makes it easy to decode a QR code that was emailed to you, embedded in a PDF, or shared in a chat message, all without reaching for your phone.

    Why browser-based scanning makes sense

    A browser-based scanner has three structural advantages over a native app: nothing to install (so no storage used and no permissions granted beyond the camera itself), instant updates (you always get the latest version, no app-store update needed), and true cross-platform support (the same tool works identically on Windows, macOS, Linux, iOS and Android). Modern browsers also expose a native Barcode Detection API on many platforms, which this tool uses automatically when available for near-native scanning speed, falling back to a proven JavaScript decoder everywhere else so the experience stays consistent.

    Privacy: what happens to your camera feed and images

    Nothing you scan is ever transmitted anywhere. The camera stream is captured using the browser’s standard getUserMedia API and analyzed frame-by-frame directly in memory; uploaded or pasted images are read locally and decoded on a canvas element — at no point does either path make a network request containing your image or video data. The only thing optionally stored is the decoded text result, saved to your own browser’s local storage so your scan history persists between visits, and it never leaves your device either. You can clear it at any time from the history panel.

    Using the scanner offline

    Once the page and its scanning library have fully loaded, the actual decoding logic runs entirely in your browser’s memory and does not require an active internet connection — camera scanning and image decoding both continue to work offline. You will need connectivity again to load the page for the first time, to open any external link a QR code points you to, or to load a fresh copy after clearing your browser cache.

    Common scanning errors and how to fix them

    • “No QR code found” — the image may be too blurry, too small, or poorly lit. Try a sharper, closer, better-lit photo, or use the “Enhance & rescan” option.
    • Camera won’t start — check that you’re on a secure (https) connection, that camera permission is granted in your browser settings, and that no other app is currently using the camera.
    • Code scans but looks garbled — this usually means a different (non-QR) barcode format was detected, or the code uses an unusual character encoding; try uploading a higher-resolution image.
    • Nothing happens after decoding a link — check your pop-up blocker; the “Open” button opens links in a new tab, which some browsers restrict without a direct click.
    • Scan works on desktop but not mobile (or vice-versa) — camera capabilities like flashlight and zoom vary by device; use image upload as a reliable fallback on any device.

    Best practices for reliable scanning

    1. Make sure the QR code fills a reasonable portion of the camera frame — not too far, not too close.
    2. Use even, glare-free lighting; avoid direct reflections off glossy print or screens.
    3. Hold the camera steady for a moment rather than sweeping across the code.
    4. For photos, use the highest resolution available and avoid heavy compression.
    5. If a live scan fails repeatedly, take a photo and use “Upload & paste” instead.
    6. Always glance at the decoded destination before opening a link from an unfamiliar source.
