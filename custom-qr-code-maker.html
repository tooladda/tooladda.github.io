Error correction: the setting that decides whether your QR works

Every QR code carries redundant data so it can still be read when part of it is dirty, creased or covered. You choose how much, and the choice matters more than any other setting on this page.

LevelRecovers fromUse when
Low (L)About 7% damageClean digital use only, where the code is never printed.
Medium (M)About 15% damageThe sensible default for most printing.
Quartile (Q)About 25% damageSmall print, packaging, or anything handled a lot.
High (H)About 30% damageRequired if you place a logo in the middle.

The rule worth remembering: a logo in the centre is deliberate damage. You are covering part of the code, and only the redundancy lets it still scan. Add a logo without raising the level to H and you will produce a code that works on your screen and fails on a printed poster.

Why some pretty QR codes do not scan

Scanners look for dark modules on a light background. Three styling decisions break that, and all three are common:

  • Inverted colours. A light code on a dark background fails on many scanners, which expect the opposite. If you want a dark design, put a light panel behind the code.
  • Not enough contrast. Mid-grey on light grey looks elegant and scans badly. Keep the foreground genuinely dark and the background genuinely light.
  • No quiet zone. A QR code needs clear margin around it — roughly four modules' worth. Crop it tight against other artwork and scanners lose the edge.

Always test the finished code with two different phones before printing a thousand of anything. It costs a minute and saves a reprint.

How big to print it

The usual guidance is that a QR code should be about one tenth of the scanning distance. A code read from arm's length, say 30 cm, wants to be around 3 cm across. A poster read from three metres wants roughly 30 cm.

Shorter data also helps, because fewer characters means fewer, larger modules. A long URL with tracking parameters produces a dense code that needs to be printed bigger to stay readable — shortening the link first is often the simplest fix.

Is my data sent to a server?

No. The code is drawn on your device, so whatever you encode never leaves the browser. No tracking is inserted either — what you type is exactly what is encoded.

What does error correction actually do?

It adds redundant data so the code still scans when part of it is dirty, creased or covered. Low recovers from about 7% damage, Medium 15%, Quartile 25% and High about 30%.

Which error correction level should I choose?

Medium is a sensible default for printing. Use Quartile for small print or packaging that gets handled. Use High whenever you place a logo in the middle, because covering the centre is deliberate damage that only the redundancy can absorb.

Can I put my logo in the middle?

Yes, and it usually looks better. Raise the error correction to High when you do — a logo at Medium may scan on your screen and then fail on a printed poster, which is an expensive way to find out.

Why does my QR code not scan?

Usually one of three things: the colours are inverted, so a light code sits on a dark background; the contrast is too low; or the quiet zone around the code has been cropped away. Scanners expect dark modules on a light background with clear margin.

Can I invert the colours?

You can, but many scanners will fail on it. If your design needs to be dark, place a light panel behind the code rather than inverting the code itself.

How big should I print a QR code?

Roughly one tenth of the distance it will be scanned from. Read at arm's length, about 30 cm, the code wants to be around 3 cm across. On a poster read from three metres, around 30 cm.

Why is my QR code so dense?

Because the data is long. Every extra character means more, smaller modules. A URL with tracking parameters produces a much busier code than a short link, so shortening the link before encoding is often the simplest fix.

What can I encode besides a website?

Anything that is text. Common uses are Wi-Fi credentials so guests can join without being told the password, contact links for business cards, payment links on invoices, and plain text on product packaging.

What size and format can I download?

You can set the pixel size before downloading, and the code exports as an image ready to place into a document, a design file or a print layout.

Should I test the code before printing?

Always, and with two different phones. Scanners vary, and the difference between working and not working is often contrast or margin rather than the data. A minute of testing saves a reprint.

Is there a limit on how much text I can encode?

The QR standard itself has a limit of a few thousand characters, but long before that the code becomes too dense to scan reliably at normal print sizes. Keep it short — a link is almost always better than the content itself.
