    What is PDF Splitting?

    PDF splitting is the process of dividing one PDF document into smaller files — either individual pages, specific page ranges, or logical chunks. A PDF splitter lets you extract only the pages you need instead of sending an entire 200-page file when your recipient cares about three pages. Unlike deleting pages (which permanently removes content from a master file), splitting creates new PDF files while leaving your original untouched on your device.

    ToolAdda splits PDFs entirely in your browser using pdf-lib. Your document is never uploaded to a server, which makes it suitable for contracts, medical records, financial statements, and HR documents that cannot leave your network.

    How to Split PDF Online

    1. Upload your PDF via drag-and-drop or Browse.
    2. Review file name, page count, size, and thumbnail preview.
    3. Choose split mode — every page, range, selected pages, every N pages, odd, or even.
    4. Configure page numbers or click thumbnails to select pages.
    5. Split and download a single PDF or multiple files as ZIP.

    Split PDF by Page Range

    Enter a range like 2-5 to create one PDF containing pages 2 through 5 inclusive. This is ideal when you need a continuous section — a single chapter, one form within a packet, or pages 10–12 of a scanned contract. The output preserves original quality because pages are copied, not re-rendered.

    Page ranges are the most common split operation in enterprise workflows. Insurance adjusters extract pages 4–9 from claim packets. Recruiters pull pages 2–3 (resume) from a multi-document scan. Teachers extract pages 15–22 (one chapter) from a textbook PDF. Unlike printing to PDF from a viewer (which can alter fonts and margins), ToolAdda's range split copies the original page objects byte-for-byte into a new container.

    Tip: check the thumbnail grid before splitting to confirm page numbers match your visual expectation — scanned batches sometimes include blank separator pages that shift numbering.

    Split Every Page into Separate PDF

    Every page mode creates one single-page PDF per page in your document. A 20-page scan becomes 20 files named document-page-1.pdf through document-page-20.pdf. Use Download all as ZIP to grab every file in one click instead of saving each individually — the workflow iLovePDF and Smallpdf charge for on heavy use, but ToolAdda offers free without upload.

    This mode shines when a single scan contains many independent documents — for example, a stack of signed receipts photographed as one PDF, or a batch of HR forms scanned sequentially. Each output file is small, easy to email, and can be renamed before sending. After splitting, run Compress PDF on individual files if upload portals enforce strict megabyte limits.

    Extract Selected Pages from PDF

    Selected pages mode combines visual and text selection. Click thumbnail tiles to toggle pages, or type comma-separated numbers and ranges like 1,3,5-7. The result is one PDF containing only those pages in ascending order — perfect for building a custom excerpt from a larger document. For simpler single-page pulls, see our Extract PDF Pages tool.

    Visual selection reduces errors compared to typing page numbers blind. Selected thumbnails highlight with a red border; the page counter updates live. Keyboard users can tab through thumbnail buttons and press Enter to toggle selection. When you type in the text field and press Tab away, the grid syncs to match — combining both input methods for speed and accuracy.

    Split Every N Pages

    Divide a long PDF into equal chunks. With N=3 on a 10-page file, you get four PDFs: pages 1–3, 4–6, 7–9, and page 10 alone. Useful for splitting bulk scans into email-sized batches or breaking reports into equal review segments.

    Split Odd and Even Pages

    Double-sided scans sometimes land odd and even pages in one file incorrectly, or you need to separate duplex scan sides. Odd pages extracts 1,3,5… into one PDF; Even pages extracts 2,4,6… into another.

    Split a PDF into Two Files

    To cut a document in half, choose Every N pages and set N to half the page count, rounded up. A 10-page file with N=5 becomes pages 1–5 and 6–10; a 7-page file with N=4 becomes pages 1–4 and 5–7. For an uneven cut — the first three pages in one file and the rest in another — run Page range twice, first 1-3 and then 4-10. The line above the page grid spells out which pages each file will hold before anything is created, and the thumbnails show the same plan: a dashed red line at every cut, and faded tiles for pages that will be left out.

    Split PDF — Frequently Asked Questions

    How do I split a PDF?

    Add your PDF, choose how to divide it — every page, every N pages, a page range, or a custom selection — then click Split PDF and download the results. The file is read and split inside your browser, so nothing is uploaded.

    Can I split PDF by page range?

    Yes. Enter a range such as 2-5 and those pages come out as one PDF. Several ranges and single pages can be combined in one go, like 1,3,5-7, to build a document from scattered pages.

    Can I split every page into separate PDF?

    Yes. Every page mode turns a 40-page document into 40 single-page PDFs, and because that is a lot of downloads, a Download all as ZIP button collects them into one archive.

    Is this PDF splitter free?

    Yes, completely. No sign-up, no trial, no page cap and no watermark on any output. Advertising pays for the site, so nothing is held back behind a paid tier.

    Do I need Adobe Acrobat?

    No. Splitting runs on pdf-lib in the page, so a current Chrome, Edge, Firefox or Safari on desktop or mobile is enough. Nothing is installed and no desktop PDF software is involved.

    Can I split scanned PDFs?

    Yes. A scanned PDF is pages of images, and those pages are copied out unchanged. The scan is not made searchable, though — no tool on the site runs OCR, so the output pages stay images.

    Will quality be reduced?

    No. Pages are copied from the source file rather than re-rendered or re-compressed, so text stays sharp and selectable, images keep their resolution, and each output page is identical to the original.

    Can I split PDF on mobile?

    Yes. Pick the PDF from your phone's storage, the Files app or Drive, tap the page thumbnails to choose what you want, and the results save to your downloads folder.

    Is my PDF secure?

    The PDF never leaves your device. It is read with the browser's File API and split in memory on your own machine, so nothing reaches ToolAdda or any ad vendor — which is what makes it safe for contracts, statements and ID documents.

    Are files deleted automatically?

    There is nothing to delete, because nothing is stored. The file exists only in the tab's memory while you work, and closing or reloading the tab clears it. No copy is written to a server or to browser storage.

    Can I download split files as ZIP?

    Yes. Whenever a split produces more than one PDF, a Download all as ZIP button appears, so you get every piece in a single archive instead of accepting a string of separate downloads.

    Can I extract selected pages?

    Yes. Click the page thumbnails you want, or type a selection such as 1,3,5-7. If you need those pages in the order you picked them rather than document order, use PDF Extract instead — that is the difference between the two tools.

    Can I split large PDF files?

    Around 100 MB is comfortable. There is no hard cap in the tool; the limit is your device's memory, because the whole document is held in RAM while it is split, so a phone runs out well before a desktop does.

    Does it work in browser?

    Yes, entirely. Current versions of Chrome, Edge, Firefox and Safari are supported on desktop and mobile. The whole split happens inside the page — there is no server step and no extension to install.

    Can I split PDF without watermark?

    Yes. Every output PDF is clean: no watermark, no footer line, no added cover page and no ToolAdda branding anywhere in the file.

    Are my PDFs uploaded to a server?

    No. There is no upload step — the file picker passes the PDF straight to JavaScript in your tab and the split finishes on your device. You can verify it in the browser's network tab, or by going offline once the page has loaded.

    How do I split a PDF into two files?

    Choose Every N pages and set N to half the page count, rounded up — a 10-page PDF with N=5 gives pages 1–5 and 6–10. For an uneven cut, use Page range twice, for example 1-3 and then 4-10.

    Can I see which pages go into each file before splitting?

    Yes. As you change the mode or type page numbers, the line above the page grid lists every file the split will create. The thumbnails show the same plan: a dashed red line marks each cut, neighbouring files are tinted in alternating colours, and pages that will be left out are faded.
