What is a PDF to image converter?

A PDF to image converter rasterizes each page of a Portable Document Format file into a standalone image file such as PNG, JPG, WebP, or AVIF. Unlike simply screenshotting a PDF viewer — which captures whatever zoom level and UI chrome happen to be on screen — a proper converter uses the PDF rendering engine to draw vector text, embedded fonts, and images at a precise resolution you control. Need the reverse? Use our Images to PDF converter after editing exported pages.

ToolAdda's converter runs entirely in your browser using Mozilla's PDF.js library. That architectural choice means your document never uploads to ToolAdda or any third-party processing server. For lawyers handling privileged correspondence, HR teams exporting offer letters, or freelancers delivering client proofs, local processing eliminates an entire class of data-leak anxiety that cloud converters introduce by temporarily storing files on remote disks. Large exports can be optimized with Compress PDF on the source file first.

Beyond basic page-to-image export, this tool adds enterprise-grade controls: granular page selection with thumbnail checkboxes and range syntax, multiple output modes including vertical/horizontal long-image combine and contact-sheet grids, auto-crop of white margins, grayscale conversion, annotation rendering toggles, and a separate pipeline to extract embedded raster images at their native resolution rather than re-rendering the full page composite.

Which image format should you choose?

PNG — lossless clarity for documents

PNG is the default choice when your PDF contains text, diagrams, charts, or line art. PNG uses lossless compression, so every pixel of a black letter on white background stays crisp without JPEG ringing artifacts around edges. PNG also supports transparency — enable the transparent background option to skip the white fill and preserve alpha for overlay compositing in design tools. The trade-off is file size: a full A4 page at 300 DPI can exceed several megabytes per page.

JPG — efficient for photo-heavy pages

JPG (JPEG) applies lossy compression controlled by the quality slider. For annual reports with full-bleed photography, marketing one-pagers, or scanned magazine spreads, JPG often produces files three to ten times smaller than PNG at visually acceptable quality. JPG does not support transparency — the tool automatically fills a white background. Avoid JPG for small text or fine lines where compression artifacts become visible; use 90–95% quality for archival photo pages.

WebP — modern web standard

WebP combines lossy and lossless modes with generally superior compression efficiency compared to JPG and PNG for equivalent visual quality. All major browsers support WebP display. Choose WebP when publishing PDF page exports to websites, progressive web apps, or CDN-backed asset pipelines where bandwidth matters.

AVIF — next-generation compression

AVIF (AV1 Image File Format) delivers even smaller files than WebP at similar quality, leveraging AV1 video codec intra-frame compression. Browser support is broad in current Chrome, Firefox, Edge, and Safari releases. Select AVIF when optimizing for Core Web Vitals and mobile data savings. Note that some older desktop tools may not open AVIF yet — verify your downstream workflow before batch converting archives.

Understanding DPI, pixel dimensions, and scale

DPI (dots per inch) defines how many pixels are generated per inch of physical page size. PDF pages are measured in points (1/72 inch), so the relationship is straightforward: at 72 DPI, one PDF point equals one pixel; at 144 DPI, one point equals two pixels; at 300 DPI, roughly 4.17 pixels per point.

ToolAdda exposes DPI through three linked controls: a preset dropdown (72, 150, 300, 600, or Custom), a numeric DPI field, a pixel width field, and a scale multiplier. Changing any one updates the others based on the first page dimensions of your loaded PDF. The live dimension preview shows exact output width and height in pixels before you commit to a long render job.

72 DPI suits quick previews and web thumbnails where the image displays at roughly screen size. 150 DPI is the balanced default for general screen reading and moderate zoom. 300 DPI matches commercial print expectations for letter and A4 documents. 600 DPI captures fine detail in engineering drawings or small-font legal footnotes but generates very large files and stresses browser canvas limits — the tool warns when output would exceed 16,000 pixels on a side.

Page selection strategies for large PDFs

Converting every page of a 400-page manual at 300 DPI is rarely necessary. ToolAdda's selection UI is built for surgical extraction:

  • Thumbnail checkboxes — visually confirm content before selecting. Click a thumbnail to open a full preview modal with keyboard arrow navigation.
  • Quick selection buttons — All, None, Invert, Odd, and Even cover common batch patterns like extracting every other page from a duplex scan.
  • Page range syntax — type 1-5, 8, 12-20, 25- where the trailing dash means "from page 25 to the last page." Invalid ranges show clear error messages.
  • Per-file cards — when multiple PDFs are loaded, each file maintains independent selection state. The ZIP organizes outputs with filename patterns you control.

For extremely long documents, consider converting in batches — pages 1–50, then 51–100 — to keep browser memory stable. After conversion, use Merge PDF if you need to recombine processed results, or Split PDF to isolate sections before converting.

Extract embedded images vs. render pages

The Extract Embedded Images tab performs a fundamentally different operation than Convert to Images. When you render a page, PDF.js draws the entire visual composition — text as vectors, images as part of the scene, annotations if enabled — into one bitmap. Extraction instead walks the PDF operator stream looking for paintImageXObject operations and pulls the underlying raster data at its stored resolution.

Extraction shines when a PDF contains high-resolution product photos, scanned signatures, or logos embedded as image objects — you get the original pixels without re-rasterizing through a viewport. It fails gracefully when a PDF contains only vector graphics or text with no embedded bitmaps. Some exotic color spaces may not decode in the browser; those images are skipped rather than crashing the session.

For pulling specific pages as new PDF files rather than images, see Extract PDF Pages.

PDF to Text — when it works and when it doesn't

The PDF to Text tab reads the structured text layer that digital PDFs embed alongside visual rendering instructions. Copy-paste from a well-formed invoice, ebook, or government form usually works because the text is stored as character codes with positioning data.

Scanned PDFs — documents created by photographing or scanning paper and saving as PDF without OCR — contain no text layer. The PDF to Text tab will return empty or minimal output for pure scans. OCR (Optical Character Recognition) is a separate technology that analyzes pixel patterns to infer letters; this tool does not perform OCR. For scanned documents, convert pages to images first, then use dedicated OCR software, or convert images back to PDF with Images to PDF after processing.

Adjustments: rotation, grayscale, auto-crop, annotations

Rotation applies an additional 0°, 90°, 180°, or 270° rotation on top of each page's intrinsic PDF rotation metadata — useful when the source file has incorrect orientation flags.

Grayscale converts rendered output to luminance values — handy for fax-simulation, reducing color noise in scans, or meeting accessibility guidelines that prefer high-contrast monochrome.

Auto-crop white margins scans pixel data after rendering to find content bounding boxes and trims uniform white borders. Adjust tolerance when off-white paper tones or faint watermarks confuse the detector.

Render annotations / form fields controls whether comment bubbles, highlight markup, and filled form widgets appear in the output. Disable for clean base-page exports; enable when the annotated version is the authoritative record.

Working with scanned PDFs

A scanned PDF is essentially a container of page images already — converting scanned pages to PNG or JPG re-encodes those images at your chosen DPI and format. Higher DPI does not invent detail that wasn't captured during scanning; it interpolates existing pixels. For archival scans, match or slightly exceed the original scan resolution rather than defaulting to 600 DPI blindly.

If scanned PDFs are too large for email after conversion, run the original through Compress PDF before or after your image workflow depending on whether recipients need PDF or image format.

Password-protected PDFs

When you open an encrypted PDF, the browser prompts for the password. Passwords are used locally to decrypt the file in memory — they are never transmitted. If you need to remove encryption permanently before sharing images, use a dedicated unlock tool first, then convert. To add protection after reassembling documents, try Protect PDF.

PDF to image converter — frequently asked questions

Is this PDF to JPG converter free with no upload?

Yes. Your PDF never leaves your device — all rendering happens locally in your browser using PDF.js. Nothing is sent to a server.

What DPI should I use?

Use 150 DPI for general screen viewing, 300 DPI for print-quality output, and 72 DPI for quick web previews. Higher DPI (600) is useful for zooming into fine detail but produces much larger files.

What's the difference between PNG and JPG here?

PNG is lossless and supports transparency, which is best for documents with text or sharp lines. JPG uses lossy compression with a quality slider, producing much smaller files, which is better for photo-heavy pages. WebP and AVIF offer the best compression of the lossy options.

Can I convert only some pages?

Yes — use the thumbnail checkboxes, the Select Odd/Even/Invert buttons, or type a page range like "1-5, 8, 12-20, 25-" to select exactly the pages you need.

Does it work with scanned PDFs?

Yes, for converting to images — a scanned PDF is just a sequence of page images, so rendering to PNG/JPG works normally. The "PDF to Text" mode, however, only works on text-based PDFs, not scans, since it reads embedded text rather than performing OCR.

Is there a page limit?

There's no hard page limit, but very long PDFs (500+ pages) at high DPI can use a lot of memory and take longer, since pages are processed one at a time to keep the browser responsive. Lower the DPI or convert in smaller batches if you run into slowdowns.

Why is my output blurry?

Blurriness usually means the DPI was set too low for how large you're viewing or printing the image. Try increasing the DPI (300 for print) or checking the live pixel-dimension preview before converting.

Can I convert PDF to WebP or AVIF?

Yes. Select WebP or AVIF in the format dropdown and adjust the quality slider. These formats produce smaller files than JPG at similar visual quality for web use.

Can I combine pages into one long image?

Yes. Set Output mode to "Combine into one long image" and choose vertical or horizontal stacking with an optional gap in pixels between pages.

How do I extract photos embedded inside a PDF?

Use the Extract Embedded Images tab. It pulls raster images at their stored resolution — different from rendering the full page appearance.

Can I convert password-protected PDFs?

Yes. Enter the password when prompted. The password is used only locally in your browser and is never uploaded.

Can I auto-crop white borders?

Yes. Enable Auto-crop white margins and adjust the tolerance slider if off-white backgrounds are trimmed too aggressively or not enough.

Does it include PDF annotations in the output?

By default, yes — comments and form fields render into the image. Uncheck "Render annotations / form fields" for clean base pages only.

Can I convert multiple PDFs at once?

Yes. Upload several PDFs on the Convert tab. Selected pages from all files export into one ZIP, with subfolders per source file when multiple PDFs are loaded.

What is Quick JPG mode?

Quick JPG instantly converts page 1 at 150 DPI to a single JPG file — ideal for thumbnails and preview images without configuring the full tool.

Does PDF to Text work on scans?

No. It reads embedded text layers only. Scanned documents require OCR software — this tool does not perform OCR.

Can I use this on my phone?

Yes. Upload from your mobile files app, select pages, and download the ZIP. A sticky Convert button appears at the bottom on small screens.

Are my PDFs uploaded to a server?

No. All conversion runs entirely in your browser. Only the page and PDF.js library load from the network — not your document bytes.

Why is my PDF to image output blurry?

Blurriness usually means the DPI was set too low. Try increasing to 300 DPI for print or check the live pixel-dimension preview before converting.

Does it render PDF annotations and form fields?

Yes, by default. Uncheck Render annotations / form fields if you want only the base page content without overlays.

What filename pattern tokens are supported?

Use {filename}, {n}/{nn}/{nnn} for page numbers (zero-padded), and {ext} for the output extension in ZIP filenames.

What filename tokens can I use in ZIP exports?

Use {filename} for the PDF base name, {n}/{nn}/{nnn} for page numbers with optional zero-padding, and {ext} for the output extension.

Can I download a single page without a ZIP?

Is this tool free forever?

Yes — unlimited conversions, no signup, no watermark on output images, and no paid tier required.

Why is AVIF greyed out in the format list?

Creating AVIF files needs an AVIF encoder inside the browser, and many browsers — Chrome and Edge among them — can show AVIF images but cannot yet create them from a web page. When yours can't, the option is switched off instead of quietly saving a PNG under an .avif name. Choose WebP or JPG for a similar size saving.
