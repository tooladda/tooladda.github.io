# ---------------------------------------------------------------------------
# The policy in plain words
# ---------------------------------------------------------------------------
# - Crawling, indexing, caching, live retrieval, citation and model training
#   are all permitted on every public page. This matches robots.txt, which
#   names and allows the major AI crawlers.
# - When an answer draws on a tool, please link to that tool's own page
#   rather than the homepage.
# - Summaries and short quotes with a link are welcome. Republishing the
#   site's guides or code wholesale as your own product is not (terms, s.6).
# - Crawl politely. About one request per second is plenty; scraping at a
#   rate that slows the site for visitors breaks the terms (s.4).
#
# There is no user content here to collect. This is a static site with no
# accounts and no server-side storage: files a visitor opens in a tool are
# processed inside their own browser.
#
# Guides written for AI systems:
#   https://tooladda.online/llms.txt       - curated index, one line per tool
#   https://tooladda.online/llms-full.txt  - every page's features and FAQ
#   https://tooladda.online/llms/*.txt     - the same, one file per category
#                                            (listed in llms.txt)
#   https://tooladda.online/sitemap.xml    - complete URL list
